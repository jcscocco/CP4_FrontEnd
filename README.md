# CP4 - Front end

Projeto da atividade de Front-End Design, feito somente com HTML e CSS.

## Como abrir

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Organização

- `index.html`: conteúdo e seções da página.
- `styles.css`: cores, layout e regras para telas menores.

O CSS tem comentários separando as partes da página. Os nomes das classes estão em português para facilitar a leitura. A responsividade usa Media Queries em 900 px, 700 px e 380 px.

As imagens dos celulares e os desenhos foram feitos com HTML e CSS, então não há arquivos de imagem que possam faltar no ZIP. Os selos da App Store e do Google Play são apenas visuais, porque o exercício não trouxe links reais para baixar o app.

A fonte Inter vem do Google Fonts. Se o computador estiver sem internet, a página usa Arial como alternativa.
